# 把碎片知识结晶回 platforms 文档

知识结晶任务。范围：$ARGUMENTS（缺省 = 全部端 + bridge）。

1. **检索记忆**：回顾本会话及近期对话中关于目标端的高价值观察，重点找这几类：
   - 反复被查询/纠正的代码结构事实（入口点、模块职责、构建命令）；
   - 踩过的坑及其解法（编译问题、平台特性差异、WebView 兼容问题）;
   - 已被验证的约定（命名、目录、mock 开关方式）。
2. **对照现有文档**：读 `context/platforms/<端>.md`（bridge 则读 `context/bridge.md`），找出记忆中有但文档中没有、或与文档矛盾的条目。
3. **合并写回**：把新知识合并进文档对应小节，保持每份 platforms 文档在一页纸以内（约 100 行）——超出则压缩旧内容，优先留下"会让下一次任务少走弯路"的信息。矛盾条目以最新实际验证结果为准，并删掉过时内容。
4. **提交**：`git add context/ && git commit -m "docs(platforms): distill <端> <日期>"`。
5. 汇报本次结晶了哪几条、删掉了哪几条过时内容。
