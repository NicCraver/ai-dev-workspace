# Impl Notes：markdown 标题上蓝 + 自己发气泡调浅

> 平台无关。最后更新：2026-09-01

## 需求

1. 智能体 / 机器人消息里的 markdown 标题，从正文黑改成 primary 蓝，观感对齐 web 的个人 AI 框。
2. 自己发送消息的气泡底色调浅一档。

## 规则

- 标题色 `#3E7EFF`，**只作用于 H1–H4**。H5 / H6 字号本来就不缩小（跟正文一样大），再上色会跟正文里的强调文字混淆，保持正文色。
- 标题里的链接保持链接色，不被标题色盖掉。两者同为 `#3E7EFF` 时看不出差别，但下划线 / 点击态仍归链接管，实现上不要粗暴整段覆盖颜色。
- 自己发的气泡底 `#F0F5FF`，收到的仍是白。三端此前不一致（PC 实际生效 `#CCE0FE`、安卓 / iOS `#DEE8FF`），这次统一。
- 气泡变浅后**不要**跟着调 markdown 里的半透明黑（表格线 22%、表头 8%、代码 8/10%、引用 28%、hr 12%）。它们本来就是为「淡蓝 / 白两种底都能看清」选的，底更浅只会更清楚。

## 各端实现要点

| 端 | 标题色 | 气泡色 |
|---|---|---|
| PC | 全局 markdown 样式表里给 h1–h4 加 `color` | 三套气泡克隆各有一份 `.message-item-self` 的底色 / 边框色，要一起改（会话列表、合并转发详情、回复列表） |
| 安卓 | Markwon 的 span factory **追加**一个前景色 span，按 `CoreProps.HEADING_LEVEL` 判层级。不要替换默认 factory——加粗和字号倍率都在里面 | 气泡是一张 shape drawable，被二十多处 provider 引用；只改它的 `solid` 取值，别改共享色值、也别为改名去动引用方 |
| iOS | markdown 样式对象上加「标题色 + 最高染色层级」两个可覆盖项，渲染标题时按层级染，且跳过已有独立颜色的片段 | 气泡色是一个宏，改宏即可；字号设置页另有一张气泡预览 PNG，要一并重上色否则预览与真实气泡对不上 |

## 边界

| 场景 | 预期 |
|------|------|
| H5 / H6 | 不上色，跟正文 |
| 标题里含链接 | 链接仍是链接色，可点 |
| 标题里含行内代码 | 代码底色不变，字色跟标题色（它本来就 `color: inherit`） |
| 收到的白气泡 | 不动 |
| 微信互通会话（绿气泡） | 走另一套色，不动 |
| 群已读进度条等复用 `DEE8FF` 的控件 | 不动，气泡改色不该顺带改它们 |
