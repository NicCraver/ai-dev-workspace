示例覆盖类型清单（来自三端调研汇总）： 文本 / 图片 / 文件 / 位置 / 群AI卡片 ActionCard / 嵌套合并消息 / 撤回占位 / 个人AI框 tag / 群AI框 tag / 机器人 tag / 评优徽章+星级 / 时间戳缺失兜底 / AI框定时发送调度胶囊 / 引用消息 7 种子类型（引用文本/图片/文件/位置/群AI卡片/嵌套合并消息/已撤回消息，各自摘要占位文案不同）。

评优/tag 色值已对齐 desktop 真实代码：徽章色取自 ExcellentMedal.vue colorMap（集团优秀/板块优秀=紫#8787FB，集团良好/板块良好+=蓝#4A7ADF，板块良好=绿#2A877D，和 android AppraisingTypeUtil 完全一致）；AI/机器人 tag 色取自 msg-list.vue 的 .tag-personal-ai/.tag-agent/.tag-robot；主题色改为 #3E7EFF（desktop unocss primary 精确值）。

本轮按 10 张真实截图二次还原：评优徽章改成「六边形年/季图标+胶囊+竖分隔线+星」（星色按集团=金/板块=灰，实拍配色，非猜测）；文件消息按类型给实底色图标，未知类型灰底问号；新增「来自XXX个人AI框」归因胶囊（气泡下方独立一行，区别于昵称行的 tag）；群AI卡片改成"蓝色提示条+嵌套小卡+行动中心归属胶囊"结构。

逻辑修正（不只是样式）：① 评优徽章只挂真人 senderId（查账户考核库），个人AI框/群AI框/机器人这三种 tag 身份互斥于评优，不会同时出现——之前误把评优挂在机器人头像上，已改成挂在真人（李博雅/苑立杰）身上；② 时间统一紧跟昵称/tag自然接排，不再顶格推到行最右——10张截图里没有一例把时间推到行尾，之前 margin-left:auto 是猜的；③ 合并详情页内点 quote-block 会弹出「N条回复」弹窗（对齐 android/iOS 真实实现，PC 目前该功能有缺口——见下方"引用消息 7 种子类型"，除已撤回态外都可点，点这里试试 →）；④ 个人AI框定时发送的调度时间胶囊「⏰ 每天20:32」只有账户本人可见，群AI框定时发送的调度胶囊则群内所有人可见——两种AI框身份的可见性规则不一样，别混着实现；⑤ 回复弹窗里每条回复本身就是一条 ReferenceMessage，自带引用块，不是纯文本气泡——之前3条回复写成了光秃秃的纯文本，不真实；"回复"这个动作本来就是带引用发的，所以列表里原样渲染出来自然带着 quote-block（还原截图16结构）。
