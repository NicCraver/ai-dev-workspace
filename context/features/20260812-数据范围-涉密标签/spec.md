# Spec：数据范围-涉密标签

> 由 Superpowers brainstorm 产出，覆盖模板。最后更新：2026-08-13

## 背景与目标

「选择数据范围」相关弹窗/页面（个人 AI 框数据来源选择）需要对涉密的人员/群组给出可见标记：人力部门人员、公司全员群，其聊天记录与文件涉密，不参与 AI 分析。用户需要在勾选数据范围时一眼看出哪些对象涉密，并能查看统一的说明文案。

同时借这次改动，把现有「已离职」后缀文案（`姓名（已离职）`）统一改造成与「涉密」同款 tag 组件展示，去掉括号写法。

成功标准：四端（web / android / ios / desktop）「选择数据范围」相关的全部/群组/组织架构/搜索/已选（PC）及选择联系人/选择已有群组/全部/搜索/已选（移动）场景，涉密与已离职对象均以 tag 形式正确展示；点击说明入口能看到固定文案；姓名/群名过长时 tag 不被挤丢。

## 用户流程

1. 用户打开「选择数据范围」弹窗/页面，候选清单（`getAllImDialogue` 一次性拉取，弹窗内存缓存，现有机制不变）。
2. 弹窗渲染人员/群组行时，若该项 `ignoreChatType===1` → 行内追加「涉密」tag；若私聊 `privateInfo.leave===1` → 追加「已离职」tag（与涉密可共存，涉密在前）。
3. 组织架构 / 搜索 / 已选等不直接携带这两个字段的 tab：前端用已拉取的 `getAllImDialogue` 列表建 `accountId/groupId → {secret, resigned}` 查找表，渲染时按 id 回填，不改动组织架构树等其他接口。
4. 用户点击弹窗底部工具栏的「[图标]涉密」按钮 → 弹出说明气泡（固定文案，见下）；再次点击该按钮或点击气泡外任意位置 → 收起。行内 tag 本身不可点、不弹气泡。
5. 姓名/群名过长时，tag 优先完整展示，姓名/群名用标准 CSS 省略号截断。
6. 用户确定/取消，走现有提交流程，不受本功能影响。

## 范围

- 本期做：
  - 四端「选择数据范围」全部相关 tab/页面新增「涉密」「已离职」两种 tag 展示（同一 tag 组件、不同配色）
  - 标题栏说明图标按钮 + 点击展开/收起说明气泡（文案走 `getSecretButtonTip`）
  - 「已离职」由现有姓名后缀 `（已离职）` 改造为独立 tag，与涉密 tag 视觉统一
  - web 端补涉密图标素材 `secret.svg`（已给的 SVG）
- 本期不做：
  - 不改组织架构树、群列表等其他接口结构（`ignoreChatType` 仍复用既有字段）
  - 与本功能无关的工作区遗留改动（`saveAgentSetInfo` / `getAgentSetInfo` / `hideChat` 等 Agent 设置域改动）不属于本功能范围，不合并进来

## 各端差异点

默认四端行为一致：数据来源判定、tag 文案/配色、说明气泡文案与交互、姓名截断规则均相同。

> 移动端「选择数据范围」现状 100% 走 wnsdk 桥接到 android/ios 原生页面，`m/` 入口无对应 web 弹窗/页面（同结构的「选择 AI 框」才有 web 版 popup）。本期移动端只改 android/ios 原生代码，**不新建** mobile web 页面。

| 差异点 | web | android | ios | desktop |
|--------|-----|---------|-----|---------|
| 落点页面结构 | PC 端弹窗（Tab：全部/群组/组织架构 + 搜索 + 已选浮层） | 移动原生页（全部 + 选择联系人/选择已有群组 子页 + 搜索 + 已选浮层） | 同 android | 同 web（PC 弹窗结构，桌面壳） |
| 涉密图标素材 | `src/assets/svg/secret.svg`（已建） | 需按 android 图标资源规范补（矢量，同一份路径数据） | 需按 ios 图标资源规范补 | 复用 web 资源（同仓/内嵌） |
| 已离职 tag 改造范围 | `dataScopeModel.js` 的姓名后缀逻辑 + 各渲染点（`AiBoxRow`/`OrgPicker`/搜索行/已选 chip） | 对应原生列表适配器 | 对应原生列表适配器 | 复用 web 组件 |

## 依赖的接口

- `context/contracts/personalAiFrame/getAllImDialogue.d.ts`：`ignoreChatType`（1-忽略聊天记录/涉密；0-不忽略）已在契约中，后端已上线，直接接入，无需 mock 过渡。
- `privateInfo.leave`（同一契约文件既有字段）：已离职判定，逻辑不变，只改展示形式（后缀文案 → tag）。
- `context/contracts/personalAiFrame/getSecretButtonTip.d.ts`：POST `/personalAiFrame/getSecretButtonTip`，无入参，`data` 为涉密按钮气泡文案字符串（配置 `personal.ai.frame.secret.tip.text`）。后端状态「开发中」。
- 组织架构树 / 群列表 / 搜索等接口：本期不改，涉密与已离职标记由前端按 id 从 `getAllImDialogue` 缓存回填。

## Tag 视觉规格

| | 涉密 | 已离职 |
|---|------|--------|
| 文案 | 涉密 | 已离职 |
| 背景色 | `#FFF3DA` | `#E5E5E6` |
| 文字色 | `#FEAC00` | `#8F959E`（复用项目既有 `grayMedium` token） |
| 圆角 | 2px | 2px（同组件） |
| 共存顺序 | 涉密在前，已离职在后，两者并排 | — |

> 已离职配色取自截图采样，非精确设计稿值，如与实际设计稿有出入以设计稿最终值为准。

## 说明气泡

- 入口：弹窗/页面底部工具栏「[涉密图标]涉密」按钮（非行内 tag）
- 交互：点击切换显示/隐藏；点击气泡外任意区域关闭
- 文案：打开「选择数据范围」时请求 `getSecretButtonTip`，用回参 `data` 字符串展示；不再写死前端文案
- 接口失败/未返回时的降级策略待联调确认（是否回退到旧静态文案，或展示空气泡）
