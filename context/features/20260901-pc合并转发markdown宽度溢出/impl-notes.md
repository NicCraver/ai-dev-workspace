# Impl Notes：合并转发详情里 markdown 宽表溢出

> 平台无关。最后更新：2026-09-01

## 现象

同一条带表格的智能体卡片：放进合并转发（聊天记录）后再打开，整卡右侧被裁掉，表也滑不了。

## 根因

横滚容器必须**比表窄**，表按内容变宽，容器按列宽，才能出现横条。

合并转发详情里，气泡外还有一层横向 flex（头像旁那一行）。这一行默认按内容定宽，会被表撑得和表一样宽。于是：

1. 横滚容器跟表一样宽，判定「没有溢出」，不画横条
2. 再外一层把超出窗口的部分裁掉
3. 正文按撑开后的宽度折行，窗口里只看得到左半截

只锁「消息列」不够——列可以被裁，里面那一行仍跟表一样宽。必须把**包着白底气泡的那一行**也锁在列宽内。横滚容器要跟列走（宽度 100%），不能只写「不超过 100%」——父级被表撑开时 100% 就是表宽。

## 修法

- 包着气泡的那一行：允许缩到列宽，且不超过列宽
- 横滚容器跟列等宽；表仍按内容变宽
- 不要改成把表压成一列或禁止变宽

## 边界

| 场景 | 预期 |
|------|------|
| 合并转发详情 | 卡贴列宽，正文折行，宽表横滚 |
| 会话 / 回复列表 | 同一套锁，避免再漏 |
| 窄表 | 无横条 |
| 短文本气泡 | 仍随内容变窄，不被强行拉满 |
