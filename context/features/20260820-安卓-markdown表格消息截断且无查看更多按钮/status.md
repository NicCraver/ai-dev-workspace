## 根因（详见 impl-notes.md 第一节）

A~F 全部出自**同一个根**：段栈与 `tv_content` 都是 `match_parent` 宽、宿主 `ll_message`
是 `wrap_content` 宽，LinearLayout 因此跑两轮测量（`forceUniformWidth`），**两轮的宽度和
高度都可能不一致，而宿主的总高只认第一轮**。

解法三条：高度恒按 `UNSPECIFIED` 测 + 宽度锁定为上次布局实际宽度 + `EXACTLY` 轮原样返回父级值
（对不上时请求下一帧重算）。普通 TextView 无法重写 `onMeasure`，新增 `ZXStableWidthTextView`
承担锁宽职责，`tv_content` 换用它。
