# 推送后列表刷新规则（aiBoxSendMessage → Web）

> 最后更新：2026-07-20  
> 适用范围：web 个人 AI 框（PC `PersonalAiChat` / 移动 `MPersonalAiChatWrapper`）收到壳或原生推送后如何刷列表。  
> 角标链路见 `3端AI框角标推送.md`（本文只谈 **内容列表**，不谈黄角标数字）。

---

## 1. 三层列表

```
AI框列表 (agentList)           ← POST /personalAiFrame/list
  key: agentId / belongType+belongId
        │ 选中某个 AI 框
        ▼
历史会话列表 (History)          ← POST …/getSessionList（belong 维度）
  key: session.id  ←→ 推送 sessionIds
        │ 选中某个 session
        ▼
当前消息列表 (Chat.messages)    ← POST /sessionMsg/getMessageList（sessionId）
  key: 当前 sessionId
```

推送里的 `sessionIds` = **AI 会话 id**（History / Chat 层），不是 AI 框的 `agentId`。

选择弹窗（最近联系人 / 群组 / 组织）与推送无关，**不因推送刷新**。

---

## 2. 三种情况怎么刷

| # | 情况 | AI框列表 `list` | 历史 `getSessionList` | 当前消息 `getMessageList` |
|---|------|-----------------|----------------------|---------------------------|
| 1 | 无 / 空 `sessionIds` | 不刷 | 不刷 | 不刷 |
| 2 | 有 `sessionIds`，当前会话 **不在** 集合内 | **刷** | 不刷 | 不刷 |
| 3 | 有 `sessionIds`，当前 `sessionId` **在** 集合内 | **刷** | **刷** | **刷**（带当前 sessionId） |

说明：

- **情况 1**：壳约定账号未命中或 map 值为空时 **不通知 Web**；若仍收到空数组，直接忽略。
- **情况 2**：只更新侧栏副标题 / 时间 / 排序 / 未读等；不打断用户正在看的对话。
- **情况 3**：`list` + `getSessionList` + `getMessageList`；消息刷新按当前 `sessionId` 再拉，**不要**整页重挂 Home/Chat。

`list` 刷新入参：沿用当前 `filterTypes` + `exemptAgentIds`，`skipGetFilter=true`（不必再打 getFilter）。

---

## 3. 接口职责（推送场景）

| 接口 | 推送时是否调用 | 说明 |
|------|----------------|------|
| `POST /personalAiFrame/list` | 情况 2、3 | AI框列表 |
| `getSessionList` | 仅情况 3 | 历史会话列表（belong 维度） |
| `POST /sessionMsg/getMessageList` | 仅情况 3 | 当前会话消息；代码封装名多为 `getMessageListBySession` |
| `POST /sessionMsg/getLastSessionMessage` | **不调用** | 只用于「打开 AI 框 / 尚无具体 session」入口；推送命中必带非空 `sessionIds`，不走此接口 |

## 4. 判定伪代码

```js
async function onAiBoxSendMessage(sessionIds) {
  if (!sessionIds?.length) return // 情况 1

  await loadAgentList({ skipGetFilter: true }) // 情况 2、3 都刷 list

  const current = currentSessionId // Home / Wrapper 当前会话
  if (current && sessionIds.includes(String(current))) {
    // 情况 3
    await refreshHistoryList({ soft: true })   // getSessionList
    await refreshCurrentMessages(current)      // getMessageList
  }
  // 情况 2：到此结束
}
```
